# Waad 100% - Full Telegram Bot (Python)

هذه نسخة متقدمة لبوت إدارة جروبات مشابه لبوت "وعد" تحتوي على معظم أوامر الإدارة والحماية والرتب باللغَة العربية وبدون "/" في بداية الأوامر.

## مميزات مهمة
- رتب: مالك أساسي (OWNER_IDS)، منشئ (creator)، مدراء (managers)، أدمنز (أدمن).
- أوامر نصية بالعربي بدون شرطة مائلة.
- قفل الدردشة، قفل روابط، قفل ميديا، قفل ملصقات.
- مسح رسائل (يعتمد على سجل الرسائل المُخزن).
- تثبيت/الغاء التثبيت.
- فلتر كلمات + تحذيرات.
- كتم/فك كتم مع تتبع.
- عرض القوائم (المحظورين، المكتومين، المدراء، الأدمنيه).
- '.' يرد بيوزر البوت، 'الاوامر' لعرض قائمة الأوامر.

## تشغيل سريع
1. ثبت المتطلبات:
```
pip install -r requirements.txt
```
2. عيّن التوكن كمتغير بيئة:
```
export WAAD_BOT_TOKEN="توكن_البوت"
```
أو عدّل المتغير TOKEN داخل الملف `waad_full_bot.py`.
3. (اختياري) عدّل OWNER_IDS في رأس الملف لو عايز تكون انت المالك الأساسي.
4. شغّل:
```
python waad_full_bot.py
```
5. ادخل البوت على الجروب واعطه صلاحيات Admin كاملة (خصوصًا تغيير الصلاحيات، حظر، حذف رسائل، تثبيت رسائل).

## ملاحظات
- هذا السورس يغطي معظم أوامر وعد الأساسية. لو محتاج إضافات خاصة أو ضبط الصيغ، أقدر أعدلها.
- حفظ البيانات يتم في ملف `bot_data.json`.
